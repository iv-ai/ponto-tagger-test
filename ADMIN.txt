BEFORE SENDING TO ANY CANDIDATE — SET THE ANSWER KEY
-----------------------------------------------------

This only needs to be done once (or when you want to update the answers).

1. Go to the candidate test link above
2. Click the guideline link on the page and read it
3. Type exactly: I have fully read the guidelines
4. Enter name: poiMaster   <-- must be exact, case-sensitive
5. Tag all 42 items
6. Click Submit

Your answers are now saved as the master answer key. All candidate
submissions will be automatically scored against it.

To update the answer key later: repeat the same steps. It overwrites
the previous one.

VIEWING RESULTS
---------------

1. Go to the results viewer link above
2. On your first visit, paste the Apps Script URL and click "Load Results"
   (it saves in your browser — you won't need to paste it again)
3. Click "Refresh" anytime to pull the latest submissions

What you'll see:

- Green banner at the top = answer key is set. Yellow = not set yet.
- Candidate cards = one per submission, sorted by score (highest first)
  Each card shows: score %, correct/total, breakdown by tag type
- Results table = every item x every candidate
  Green cell = correct answer. Red cell = wrong answer.
  Yellow column = the poiMaster answer key for reference
  Click any image thumbnail to expand it full size
- Export CSV button = downloads a spreadsheet with all answers and scores


HOW SCORING WORKS
-----------------

Each of the 42 items is scored as correct (1) or incorrect (0) against
the poiMaster answer key. Score = correct / total x 100.

The 5 tag options are:
  Ready              — output image is good to go
  Needs Design Review — needs a minor design edit
  Regenerate         — needs to be regenerated
  Needs New Input    — input image is unusable
  Flag               — location is a skip category


TROUBLESHOOTING
---------------

Start button won't activate
  → Candidate must click the guideline link AND type the exact phrase:
    "I have fully read the guidelines"

Submission fails
  → Check the Apps Script is deployed with "Anyone" access.
    Go to script.google.com → the project → Deploy → Manage deployments.

Results viewer shows no data
  → Make sure the Apps Script URL is pasted in the viewer correctly.
  → Try clicking Refresh.

Answer key missing (yellow warning in viewer)
  → Go to the test and submit as poiMaster first.

Need to swap a test image
  → Get the place ID from the production tool
  → Share it with the developer — they'll update the file within minutes.

Need to re-deploy Apps Script after a code change
  → Go to Extensions > Apps Script > Deploy > Manage deployments
  → Edit the existing deployment (do NOT create a new one — the URL will change)
